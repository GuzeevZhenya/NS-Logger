# План: аудит спавна VPP

PRD: `docs/prd/vpp-spawn-audit.md`

## Фаза 1 — сквозной путь

Цель: открыть UI, выбрать даты и админа, увидеть спавн с именем и запретом.

Слои: парсер, каталог, API, UI.

Задачи:

1. Каркас Vite/React + Hono, настройки пути к Logging.
2. Парсер `Log_*.txt` и vitest на фикстурах (self / player / preset, полночь, +3ч).
3. Каталог `items.json` (имя + запрет) и сид `admins.json` из текущих логов.
4. API: индекс, фильтр по дате и SteamID/нику.
5. UI: диапазон, Все/админ, таблица, красный запрет.

Критерий: в браузере Pupok, 19.10.2026, PDA с названием; `CarTent` или лодка — запрет. `pnpm test` зелёный.

## Фаза 2 — удобство

Цель: быстрее находить нарушения и уносить выборку в Discord.

Слои: API, UI, скрипт каталога.

Задачи:

1. Сводка: всего / запрет / топ предметов.
2. Поиск, фильтр «только запрет», тип спавна.
3. Схлопывание пачек ×N за секунду.
4. Бейдж неизвестного класснейма, экспорт Discord-текста.
5. Смена папки логов, кнопка обновления каталога.

Критерий: фильтр «только запрет» оставляет красные строки; экспорт скачивает txt; смена папки перечитывает индекс.
