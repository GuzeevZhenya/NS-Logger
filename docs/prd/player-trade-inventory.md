# Логи игроков ModernLogger

Дата: 2026-11-17
Статус: draft

## Цель

В том же журнале видно покупки/продажи, инвентарь, двери/ворота и действия с машинами из ModernLogger (`Day_*`), рядом с действиями админов VPP.

## Сценарии

- Куратор включает «Покупки / продажи» → BUY/SELL с ником, предметом, ценой и координатами.
- Куратор включает «Инвентарь» → перемещения предметов с класснеймом.
- Куратор включает «Двери / ворота» → открытие/закрытие ворот с позицией.
- Куратор включает «Машины» → двери машины, двигатель, урон; класс техники и координаты.
- Куратор задаёт `playerLogDir` → индекс читает папки `Day_*` / `NN`.

## В скоупе

- Парсинг `*.log` из `Day_DD-MM-YYYY` и папок вида `17`
- Категории: trade, inventory, doors, vehicle
- `playerLogDir` в `settings.json`
- Каталог имён для класснеймов предметов/техники
- Фильтры дат / поиск / экспорт

## Не в скоупе

- Отдельные события «сел / вылез / поставил машину», если их нет в ModernLogger (в текущих логах их нет; позиция машины берётся из дверей/двигателя)
- Рубка, разделка, ловушки, банк трейдера — позже
- Отдельный UI «игроки вместо админов»

## Ограничения

- Корень логов: `D:\!!!Лабы\новая\123` (папки `Day_*` и `17`)
- SteamID из имени файла, ник из строки
- Время уже локальное, без +3
- Игроки не попадают в список админов

## Критерии готовности

- Чипы trade / inventory / doors / vehicle со счётчиками
- Видны BUY и открытие двери машины с координатами
- `pnpm test` зелёный
- В settings указан `playerLogDir`
