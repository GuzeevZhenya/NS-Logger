# План фаз

Прочитай PRD. Если его нет — сначала скилл `prd`. Сохрани `docs/plans/<тот же kebab>.md`.

На каждую фазу: цель, какие слои, до 5 задач, проверяемый критерий.

Правила:

- Первая фаза — тонкий сквозной путь через все слои
- Фаза заканчивается работающим результатом
- Бэкенд и фронтенд одной фичи — разные фазы
- Не добавляй задачи, которых нет в PRD
- Проверку (тест или браузер) закладывай внутрь фазы, не отдельной фазой в конце
