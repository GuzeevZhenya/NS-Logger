# Аудит спавна VPP

Дата: 2026-11-07
Статус: draft

## Цель

Админ сервера за минуту видит, кто из состава и что заспавнил за выбранные дни, с человеческими названиями предметов и явной пометкой запрещённых.

## Сценарии

- Куратор открывает программу → видит список админов из текущих логов и спавн за последние 30 дней.
- Куратор выбирает одного админа и диапазон дат → таблица только его спавна.
- Куратор включает «только запрещённые» → в списке остаются предметы с пометкой запрета.
- Куратор ищет класснейм или название → таблица сужается.
- Куратор копирует/скачивает выборку → текст в формате Discord Admin Activity.
- Куратор меняет папку `Logging` и обновляет индекс → события читаются из нового пути.
- Куратор обновляет каталог из таблицы → имена и запрет подтягиваются заново.

## В скоупе

- Чтение сырых `Log_*.txt` из папки Logging
- Фильтр по датам и админу (все или один)
- Название предмета из каталога, если есть
- Подсветка запрета (таблица + локальный доп. список)
- Сводка, поиск, схлопывание пачек, неизвестные класснеймы
- Экспорт Discord-текста
- Смена папки логов и обновление каталога

## Не в скоупе

- Телепорты, кики, погода и прочие действия VPP
- Онлайн-сервер, аккаунты, облако
- Правки Permissions / credentials
- Установка как Windows .exe (достаточно `pnpm dev`)

## Ограничения

- Время в UI — локальное, +3 часа к времени сервера в логе
- Секреты VPP не читаются
- Каталог лежит файлом, без запроса в таблицу на каждый фильтр
- Список админов изначально засеян из уже лежащих логов

## Критерии готовности

- В браузере за 19.10.2026 у Pupok виден `BestPDA_Module_GPS (Модуль расширения PDA)`
- Предметы с «Запрет» в таблице (например палатка/лодка) помечены красным
- Выбор «Все» и конкретного админа меняет таблицу
- `pnpm test` зелёный на парсере
- Экспорт даёт строки `Admin Activity` с `item: ClassName (Название)` при наличии имени
