# Ревью

## Всегда

- [ ] Заголовок PR по Conventional Commits, описание на русском
- [ ] Есть способ проверить: тест, сборка или сценарий
- [ ] Нет секретов в diff
- [ ] Входные данные проверяются на границе
- [ ] Новый код не ломает соседний сценарий

## Пропускать

- Lock-файлы, если зависимость не была темой задачи
- Сгенерированные миграции, если их не правили руками
- `*.log`
