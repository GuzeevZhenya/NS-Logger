# NS Logger

Журнал действий админов Vanilla++ и игроков ModernLogger: спавн, телепорты, статы, торговля, инвентарь. Видно, кто что делал, по каким дням, какие предметы запрещены.

**Сайт:** [https://dist-sigma-virid-70.vercel.app](https://dist-sigma-virid-70.vercel.app)

Ссылка публичная: ники и SteamID из журнала увидит любой, у кого есть URL. В Vercel можно включить Deployment Protection (пароль).

## Как пользоваться сайтом

1. Открой [сайт](https://dist-sigma-virid-70.vercel.app).
2. Сверху слева переключатель **Админы / Игроки / Все**:
   - **Админы** — только те, кто спавнил, телепортировал, менял статы, удалял, включал фрикам. Слева список этих людей и их действия.
   - **Игроки** — логи игроков (торговля, инвентарь, двери, машины, лут).
   - **Все** — одна лента, в списке пометка «админ» или «игрок».
3. Выбери даты, человека слева и типы событий (спавн, перемещения, статы и т.д.).
4. Запрещённые предметы подсвечиваются. Можно включить «только запрещённые».
5. Новые логи на уже открытом сайте: кнопка **выбрать логи** (файлы или папка с `Log_*.txt` / `Day_*`). Они допишутся в этом браузере, на Vercel сами не попадут.

Если страница выглядит старой — жёсткое обновление (Ctrl+F5). Снимок кэшируется около часа.

## Как работать локально

Нужны **сырые** логи VPP, не выгрузка Discord.

Папка админских логов по умолчанию:

`d:\!!!АВТО-ИВЕНТЫ\Логи\VPPAdminTools\Logging`

Внутри файлы вида `Log_2026-10-19_11-37-28.txt`. Путь игроков — `playerLogDir` в `data/settings.json` (папки `Day_*` ModernLogger).

```bash
pnpm install
pnpm catalog          # один раз: имена предметов и запрет из таблицы
pnpm seed             # один раз: список админов из текущих логов
pnpm dev              # UI http://127.0.0.1:5273/  API :8787
```

Путь к логам можно сменить внизу экрана («папка Logging» → «прочитать») или в `data/settings.json`.

### Команды

| Команда | Что делает |
|---|---|
| `pnpm dev` | Локальный UI + API |
| `pnpm test` | Тесты парсера |
| `pnpm catalog` | Обновить каталог предметов |
| `pnpm seed` | Заново собрать `data/admins.json` |
| `pnpm build` | Снимок логов + сборка статики |
| `pnpm deploy` | Сборка и выкладка на Vercel |

Админы хранятся отдельно в `data/admins.json` (ник + SteamID тех, кто спавнил, тп, менял статы, удалял, фрикам).

## Как обновить сайт на Vercel

Vercel не видит папку на диске. Снимок собирается на этой машине в `public/snapshot.json`, затем заливается статика.

```bash
pnpm build
npx vercel deploy dist --prebuilt --prod --yes
```

или одной командой: `pnpm deploy`.

После выкладки прод: [https://dist-sigma-virid-70.vercel.app](https://dist-sigma-virid-70.vercel.app)

## Данные

- `data/items.json` — имена предметов и запрет из Google-таблицы
- `data/forbidden-extra.json` — ручной доп. запрет (в т.ч. артефакты `MF_Artefact`, техника, оружие)
- `data/admins.json` — кто считается админом
- `data/settings.json` — пути к логам и смещение времени (+3 ч)

Секреты VPP (`Permissions/credentials.txt`) не читаются.
